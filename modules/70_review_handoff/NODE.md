# 70_review_handoff

## Purpose

Prepare a human-readable and machine-readable handoff for review.

## Enter When

`60_visual_plan` has passed or paused with pending images.

## Steps

1. Read draft, visual plan, and gate notes.
2. Summarize selected topic.
3. Summarize article artifacts.
4. List source gaps, image status, and publish blockers.
5. Stop before any external write action.

## Exit

Route according to `GATE.md`.
