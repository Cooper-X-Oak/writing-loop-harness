# 00_intake Rules

This node aligns with the human before creating or changing loop structure.

- Ask one high-impact question at a time.
- Do not invent loop goals, outputs, model choices, or failure policy.
- Every accepted answer must be reflected in `LOOP.md`.
- If an answer creates a new node, create that node folder with the standard files.
- Stop when `GATE.md` says the intake is complete.
