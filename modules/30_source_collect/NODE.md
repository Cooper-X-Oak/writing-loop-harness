# 30_source_collect

## Purpose

Collect enough source material to support a fact-bound public analysis.

## Enter When

`20_topic_gate` selected one topic.

## Steps

1. Read selected topic artifact.
2. Collect original sources and credible secondary sources.
3. Preserve source URLs, timestamps, and exact claims.
4. Mark source gaps explicitly.
5. Produce a source inventory.

## Exit

Route according to `GATE.md`.
