# 30_source_collect Gate

## Outcomes

- pass
- pause
- fail

## Pass

Pass when the selected topic has enough source material to build a public analysis without relying on unmarked assumptions.

## Pause

Pause when a key original source is missing but likely obtainable, or when human authorization is needed for logged-in collection.

## Fail

Fail when no reliable source can be collected for the selected topic.
