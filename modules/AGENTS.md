# modules Rules

`modules/` contains loop nodes as pure-text operational modules.

- Each node folder must contain `AGENTS.md`, `NODE.md`, `SYSTEM.md`, `CONTRACT.md`, and `GATE.md`.
- Module folders are business/process semantics, not source code packages.
- When adding, removing, or renaming a module, update `LOOP.md` and `canvas/loop.mmd`.
- Do not hide node behavior in prose outside the module folder.
