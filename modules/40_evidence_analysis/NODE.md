# 40_evidence_analysis

## Purpose

Create a fact-bound analysis package that downstream drafting can use safely.

## Enter When

`30_source_collect` has passed.

## Steps

1. Read all source inventory and source gaps.
2. Extract consensus facts, disputes, unknowns, and key claims.
3. Build a verification table using L1/L2/L3 labels.
4. Identify what must not enter the article.
5. Produce the public analysis artifact.

## Exit

Route according to `GATE.md`.
