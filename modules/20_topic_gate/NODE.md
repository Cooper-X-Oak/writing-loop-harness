# 20_topic_gate

## Purpose

Choose one topic worth spending the writing cycle on.

## Enter When

`10_hotspot_scan` has produced candidate artifacts.

## Steps

1. Read candidate list and duplicate registry.
2. Score each candidate for freshness, community signal, conflict, product impact, shareability, account fit, and duplicate risk.
3. Apply the paper-source floor: paper-only candidates cannot win unless there is proven external discussion or real-world impact.
4. Enforce daily budget.
5. Select one topic or pause for human choice.

## Exit

Route according to `GATE.md`.
