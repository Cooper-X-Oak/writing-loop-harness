# app Rules

`app/` is a React + XYFlow visualization surface for the text harness.

- The app is not a workflow source of truth.
- Read data from `workflow-data.json`, generated by `tools/export-workflow.mjs`.
- Do not write business rules, prompts, credentials, or run artifacts here.
- Keep the interface operational and dense; avoid marketing-page layout.
